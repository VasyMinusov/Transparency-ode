# API (REST, префикс /api/v1)

Swagger UI доступен на `http://127.0.0.1:8000/docs` (OpenAPI 3.1, авто из FastAPI).

## Сущности и отчёты
| Метод | Путь | Описание |
|---|---|---|
| GET | /entities?q= | Поиск сущностей по названию/ИНН |
| GET | /entities/{id} | Карточка сущности |
| GET | /entities/{id}/relations | Связи сущности |
| GET | /entities/{id}/report | Аналитический отчёт: риск, SHAP-факторы, гипотеза, контрагенты, источники |
| GET | /entities/{id}/risk | Оценка риска + факторы (XGBoost + SHAP) |
| GET | /graph | Граф целиком: узлы с оценками риска + рёбра |

## Экспертная система
| Метод | Путь | Описание |
|---|---|---|
| GET | /entities/{id}/verdict | Вердикт: факты → признаки → НПА + подобранные статьи → рекомендация |
| GET | /signals | Лента сигналов по всем сущностям (кэш по версии данных) |
| GET | /tenders | Процедуры: заявки, победители, флаги C1–C3 |
| GET | /contracts | Реестр контрактов с трёхуровневой проверкой |
| GET | /laws | Нормативная база (аннотации актов) |

## Восходящий агент и LLM
| Метод | Путь | Описание |
|---|---|---|
| GET | /entities/{id}/agent-report | Корреляции в сети + озвучивание LLM |
| GET | /agent/overview | Сводка по всей сети |
| GET/POST | /settings/llm | Настройки провайдера (offline/gigachat/ollama) |
| GET | /settings/llm/models | Установленные локальные модели (Ollama) |
| POST | /settings/llm/models/pull | Фоновое скачивание модели |
| GET | /settings/llm/models/pulls | Статусы загрузок |
| DELETE | /settings/llm/models/{name} | Удаление модели |

## Правовой слой
| Метод | Путь | Описание |
|---|---|---|
| GET | /legal/search?q= | Поиск релевантных статей НПА (TF-IDF) |
| GET | /legal/acts | Акты в корпусе |
| GET | /legal/articles/{id} | Статья по идентификатору |

## Человек в контуре
| Метод | Путь | Описание |
|---|---|---|
| GET/POST | /decisions | Журнал решений сотрудника (confirmed/rejected + комментарий) |
| POST | /load | Перезагрузка адаптеров + инвалидация кэшей |

## Пример
```bash
curl http://127.0.0.1:8000/api/v1/legal/search?q=дача%20взятки%20посредник
```
