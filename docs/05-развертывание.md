# Развёртывание и эксплуатация

## Требования
Python 3.14 + uv · Node.js + pnpm · Rust (rustup) · опционально Ollama (локальные LLM).

## Быстрый старт
```bash
make install   # uv sync + pnpm install
make demo      # сервер в фоне + оконное приложение (Ctrl+C — всё остановится)
```
Классика в двух терминалах: `make server` + `make client`.
Интерфейс без Tauri: `make server` + `make web` (браузер, localhost:1420).

## Команды Makefile
`make help` — все команды. Основные: `install`, `demo`, `server`, `client`, `web`,
`test` (pytest), `eval` (precision/recall правил), `tui` (терминальный клиент),
`reset-db`, `stego-check` (LSB-фраза в иконке), `build` (дистрибутив), `clean`.

## Переменные окружения (APP_*)
| Переменная | По умолчанию | Назначение |
|---|---|---|
| APP_DATABASE_URL | sqlite+aiosqlite:///./data/transparency.db | БД |
| APP_LLM_PROVIDER | offline | offline / gigachat / ollama |
| APP_OLLAMA_URL | http://127.0.0.1:11434 | адрес Ollama |
| APP_OLLAMA_MODEL | llama3.1:8b | активная локальная модель |
| APP_GIGACHAT_CREDENTIALS | — | ключ GigaChat (облачный провайдер) |

Настройки LLM меняются и в рантайме: раздел «Модели» в приложении или
`POST /api/v1/settings/llm`, либо в TUI: `модель ollama llama3.1:8b`.

## Локальные модели (Ollama)
```bash
ollama serve          # запуск сервера моделей
# в приложении: раздел «Модели» → скачать (например qwen2.5:7b) → сделать активной
```
Скачивание идёт в фоне, статус виден в разделе «Модели» и в `GET /settings/llm/models/pulls`.

## Терминальный клиент (TUI)
```bash
make tui
кп> проверить Мосводоканал   # отчёт + вердикт + агент
кп> сеть · сигналы · законы · модель · выход
```

## Тесты и качество
```bash
make test    # smoke + риск + граф/решения + отчёт + эксперт + агент + НПА + тендеры
make eval    # precision/recall правил → data/eval_report.json
```

## Известные ограничения (честно)
- Данные — синтетические моки (демонстрационный контур); интеграция ЕИС требует
  ЭЦП/ведомственного доступа (вне хакатона).
- Корпус НПА — конспекты статей, не дословные тексты.
- LLM-озвучивание агента недетерминировано по формулировкам (содержание — нет);
  режим offline полностью детерминирован.
