# transparency-api

Аналитическое API для подразделений по профилактике коррупционных правонарушений.
Хакатон «Код прозрачности» 2026, направление 04.

## Запуск

Требования: Python 3.14, [uv](https://docs.astral.sh/uv/).

```bash
uv sync                 # установка зависимостей (фиксируется uv.lock)
uv run uvicorn app.main:app --reload
```

Swagger UI: http://127.0.0.1:8000/docs

## Проверка

```bash
uv run pytest
```

## Данные

Источник на текущий момент — синтетический набор `data/mock_registries/procurement.json`
(генерация с фиксированным seed=42). Синтетические данные нигде не выдаются за реальные:
каждая связь несёт атрибут `data_source`. Персональные данные не обрабатываются.

## Что уже работает

- `GET /api/v1/graph` — граф целиком: узлы с оценками риска (для визуализации)
- `GET/POST /api/v1/decisions` — журнал решений сотрудника (человек в контуре)
- CORS настроен для Tauri-окна (`tauri://localhost`) и Vite-dev (`localhost:1420`)
- `GET /api/v1/entities/{id}/risk` — сквозной сценарий: граф NetworkX → признаки →
  XGBoost (seed=42) → SHAP-факторы → гипотеза (GigaChat при наличии credentials,
  иначе офлайн-шаблон). Ответ содержит честную пометку о синтетике (`data_note`).
- `uv run pytest` — smoke-тесты + тест детерминированности.

## Экспертная система (низходящая модель)

Правила R1–R10 (контракты, ЕГРЮЛ-признаки, статистические заборы Тьюки по методике OCP)
и C1–C3 (сговор по заявкам: единственный участник, идентичные цены, пары соучастников).
У каждого сигнала: правовые основания (НПА), методическое основание (Минтруд/ГУСП/OCP)
и «что запросить». Процедурный слой: GET /api/v1/tenders.
Качество правил: `make eval` — precision/recall на размеченных синтетических кейсах.

## Восходящий агент (гибрид по типу Palantir)

- `GET /entities/{id}/agent-report` — корреляции в сети вокруг сущности + озвучивание LLM.
- `GET /agent/overview` — сводка по всей сети (кластеры адресов, узлы-посредники).
- Провайдеры LLM (переменные окружения): `APP_LLM_PROVIDER=offline|gigachat|ollama`,
  `APP_OLLAMA_URL`, `APP_OLLAMA_MODEL` (локальные модели через Ollama).
- Детерминированность: вход агента — структурированные факты; LLM только формулирует
  текст и кэшируется; режим offline полностью детерминирован.
- Терминальный клиент: `python tools/tui_client.py` (команды: проверить, сеть, сигналы, законы).
